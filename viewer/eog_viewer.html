밴드패스는 눈을 좌우로 움직일 때마다 위/아래로 튀는 펄스로 정제돼요(좌↔우 방향에 따라 위/아래). 필터 버튼으로 원본→드리프트 제거→밴드패스를, 단계별 보기로 그 과정을 한 화면에서 볼 수 있어요. 아래 막대는 끌면 구간 이동, 확대는 ＋／－·마우스 휠.
필터는 원본(raw)에서 브라우저가 직접 계산합니다 — 아두이노와 동일(0.5~19.5Hz 밴드패스, 4차 Butterworth, 75Hz 기준). 드리프트 제거는 0.5Hz 고역통과로 느린 기준선 흔들림만 없애고, 밴드패스는 여기에 고주파 잡음까지 걷어낸 정제 신호예요.
JSON 형식: { "sample_rate_hz":75, "data":{ "t_ms":[…], "raw":[…] } } — eog_record.py 파일을 그대로 불러오면 됩니다.
