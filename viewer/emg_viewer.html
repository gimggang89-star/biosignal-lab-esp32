활성도는 근육에 힘을 줄 때 올라가는 곡선이에요(주먹 쥐기 등). 필터 버튼으로 원본→밴드패스→정류→활성도를, 단계별 보기로 그 과정을 한 화면에서 볼 수 있어요. 아래 막대는 끌면 구간 이동, 확대는 ＋／－·마우스 휠.
필터는 원본(raw)에서 브라우저가 직접 계산합니다 — 아두이노와 동일(밴드패스 74.5~149.5Hz, 정류, 128칸 이동합 엔벨로프 ×2, 500Hz 기준). 60Hz 전원잡음은 밴드패스 대역 밖이라 함께 제거됩니다.
JSON 형식: { "sample_rate_hz":500, "data":{ "t_ms":[…], "raw":[…] } } — emg_record.py 파일을 그대로 불러오면 됩니다.
