저주파(δ)가 큰 건 정상(1/f 특성)이에요. 눈을 감은 구간을 선택하면 알파 α가 확 올라갑니다.
알파파 실험: 아래 막대로 ‘눈 감음’ 구간을 선택하면 스펙트럼에 8–13Hz 봉우리가 솟고 알파 %가 올라가요. 필터 버튼으로 원본→밴드패스(0.5–29.5Hz)→세타/알파/베타 대역을, 단계별 보기로 원본→밴드패스→알파를 한 화면에서. 확대는 ＋／－·마우스 휠.
필터는 원본(raw)에서 브라우저가 직접 계산합니다 — 밴드패스는 아두이노와 동일(0.5~29.5Hz, 4차 Butterworth, 256Hz 기준). θ(4–8)·α(8–13)·β(13–30)는 대역별 밴드패스, 스펙트럼은 선택 구간의 FFT(Hann 창)입니다. 60Hz 전원잡음은 밴드패스 대역 밖이라 제거됩니다.
JSON 형식: { "sample_rate_hz":256, "data":{ "t_ms":[…], "raw":[…] } } — eeg_record.py 파일을 그대로 불러오면 됩니다(눈 뜸/감음 구간도 함께 표시).
