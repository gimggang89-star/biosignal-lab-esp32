11_16 EMG 실습 — BioAmp EXG Pill + ESP32 실습 파일 (빠른 진행판)
=====================================================
※ 교수님 배포 코드가 아직 없어서, PPT(9. EMG_실습_최종) 와 README 사양대로 새로 만든 코드다.
  교수님 파일을 받으면 그쪽을 우선한다. 명령 · 출력 모드 · 빈칸 ①②③ 은 PPT 와 같게 맞췄다.
※ 확인한 것: ESP32 실제 컴파일러(arduino-esp32 2.0.17)로 세 스케치 모두 컴파일 경고 0,
  PC 모의 보드 + 합성 EMG 로 R · F · P · B 출력, 빈칸본 동작, 기록 · 분석 6가지 전부 시험.
  아직 못 한 것: 실제 보드 · 실제 사람 신호 · Windows COM 포트 (오늘 처음 돌린다)

■ 준비 (약 10분)
 1. 배선: OUT → GPIO34, VCC → 3.3 V, GND → GND
          IN+ · IN- → 이두근 배 위(근육 방향으로 약 2 cm 간격), REF → 팔꿈치 뼈
    - 보드 뒷면 인쇄가 3.3 V 지원판인지 먼저 본다. 원신호가 0 이나 4095 에 붙으면 멈추고 확인
    - 수업 PPT처럼 VP(GPIO36)에 꽂았다면 emg_chain.ino 위쪽 ADC_PIN1 = 34 를 36 으로 바꾼다
 2. python\port.txt 의 COM 번호 확인 (지금 COM4)
 3. 00_설치확인.bat → 표가 나오면 파이썬 준비 끝 (보드 없이 됨)
 4. Arduino IDE 로 arduino\student\emg_chain\emg_chain.ino 열기 → 보드 ESP32 Dev Module → 업로드
    (빈칸본. 빈칸이 있어도 컴파일 · 업로드 · R · F 는 된다)
 5. 도구 > 시리얼 플로터 (115200) → P 모드 선 4개 (filt · rms · thr_on · state)
    입력창 줄 끝을 "줄 바꿈 없음" 으로 하고 R(원신호) · F(필터 후) · P 를 보내 본다
    쉴 때 작게, 주먹 쥐면 크게 흔들리면 OK → 확인 후 플로터를 닫는다
 6. (선택) 0_파형보기.bat — 파이썬 실시간 창, c 키 = 기저선 다시 학습

■ 실험 (bat 을 실행하면 화면에 "▶ 이완 / ▶ 수축!" 이 시각에 맞춰 뜨고 1초 전에 미리 알려 준다)
 실험 1  1_원신호_실험1.bat      20초  빈칸 그대로              → results\e1_time.txt · png
 실험 2  빈칸 ①② 채워 업로드 → 2_정류RMS_실험2.bat   20초   → results\e2_time.txt
          화면의 "펌웨어 기저선: RMS 평균 … MAV 평균 …" 이 0 이 아니면 ①② 성공 (0 이면 그 빈칸이 비었다고 알려 준다)
 실험 3  3_노력단계_실험3.bat    30초  10 · 25 · 50 · 75 · 100 % 를 3초씩 → results\e3_force.txt
 실험 4  빈칸 ③ 채워 업로드 → 4_수축검출_실험4.bat   18초  수축 2초 × 3번 → results\e4_detect.txt
          수축 때 보드 LED 가 켜지면 ③ 성공. 표의 "펌웨어 (k=5/3)" 줄이 전환 6 · 놓침 0 이면 잘 된 것
 실험 5  5_근피로_실험5.bat      66초  30~50 % 힘으로 60초 유지 (아프면 바로 멈춤) → e5_fatigue · e5_spec
 실험 6  (보드 2장) arduino\solution_2ch 업로드 → 6_이두삼두_실험6.bat  25초 → e6_bipolar
 시간이 없으면 빈칸 대신 arduino\solution\emg_chain 을 올려도 된다 (정답은 빈칸정답.txt)

■ 기록표에 옮길 곳 (results 폴더)
 실험 1  e1_time.txt     이완 · 수축의 x 중앙값, filt 범위
 실험 2  e2_time.txt     이완 · 수축 RMS · MAV, SNR, MAV/RMS
 실험 3  e3_force.txt    노력별 RMS · 잡음 보정 · 최대 대비 %, 직선식 · R²
 실험 4  e4_detect.txt   k 별 전환 · 놓침 · 오검출 · 지연 (지연에는 사람 반응 시간 약 0.3초가 들어 있다)
 실험 5  e5_fatigue.txt  MDF 처음 · 마지막 10초, 변화율, 기울기 · R², RMS 변화
 실험 6  e6_bipolar.txt  굽힘 · 폄 RMS, 약한쪽/강한쪽, CCI, r
 각 기록의 _기록요약.txt 에는 원신호 중앙값, 포화 경고, 펌웨어 기저선 · 임계, 수축 판정 횟수가 있다

■ 안 될 때
 [실패] 포트 · #START 를 못 받음 → 플로터 · 시리얼 모니터 닫기, port.txt, 스케치 업로드 확인
 [경고] ADC 포화 (0 · 4095 에 붙음) → 힘을 줄인다, 전극 · 3.3 V 확인 (보드 이득이 커서 세게 쥐면 포화할 수 있다)
 항상 수축으로 나옴 → 처음 3초에 힘을 뺐는지 (기저선), 다시 기록
 수축이 안 잡힘 → 빈칸 ③, 전극 접촉, 힘을 조금 더
 프레임 손실 경고 → USB 케이블, 포트를 다른 프로그램이 열었는지
 파이썬 오류 'serial' has no attribute 'Serial' → python -m pip uninstall -y serial 후 pip install pyserial
